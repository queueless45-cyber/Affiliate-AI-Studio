# Affiliate AI Studio — Curated Affiliate Skills Library

This directory contains the reusable workflow guides that match the 53-workflow catalogue in Affiliate AI Studio. It preserves the upstream folder layout so references within the guides remain usable.

## Included
- All 53 `SKILL.md` workflow guides and their per-skill references, templates, license notices, and agent metadata.
- Shared affiliate-program, offer, FTC disclosure, platform, SEO, social-data, feedback, and flywheel references.

## Important
These Markdown files are workflow instructions and reference content, not a replacement for the FastAPI application or a claim that every workflow is fully automated. The existing app catalogue remains at `backend/app/workflow-catalog.json`. Some workflows are guides; tools that call external systems still need credentials, integrations, and compliance checks.
